# 功能范围

[返回文档总索引](../README.md#文档索引)

本项目用于展示金融数据处理与特征工程的完整链路，不包含原始考核全文或内部过程材料。

1. 从公开财务来源限量采集利润表、资产负债表和主要财务指标。
2. SQLite按公司、报告期和版本组织数据，保存来源证据与观察。
3. 处理异常、缺失、重复、单位和披露时间差异，记录清洗原因。
4. 生成盈利、成长、偿债类12个特征，输出结构化特征表并支持扩展。
5. 提供质量监控、增量/修订刷新、双源核验、保存历史查询、离线重放和可重复演示。

展示范围为8家公司×8季度×3表、768条特征、96个双源核验位置和84项年报事实；正式财报三公司在目标期提供36/36实际特征，并附有披露版本目录。价格收益研究包含五组单次结果，以及三个滚动区间×三种成本×三种显式子集的9个场景。

工程验收包含GitHub双版本离线流程和本地启动验证，实际环境见[验收](acceptance.md)。12项财务定义保持stage1-v1；全市场、完整历史环境恢复、生产调度和策略有效性不作为已验证能力。详见[项目成果](progress.md)和[核验覆盖与研究](verified-coverage.md)。
