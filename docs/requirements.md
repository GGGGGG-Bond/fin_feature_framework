# 功能范围

[返回文档总索引](../README.md#文档索引)

本项目用于展示金融数据处理与特征工程的完整链路，不包含原始考核全文或内部过程材料。

1. 从公开财务来源限量采集利润表、资产负债表和主要财务指标。
2. SQLite按公司、报告期和版本组织数据，保存来源证据与观察。
3. 处理异常、缺失、重复、单位和披露时间差异，记录清洗原因。
4. 生成盈利、成长、偿债类12个特征，输出结构化特征表并支持扩展。
5. 提供质量监控、增量/修订刷新、双源核验、保存历史查询、离线重放和可重复演示。

首轮采用8家公司×2年×6字段。0.3.0扩到8公司×8季度主来源特征展示，重新采集双源96位置并核对84项年报事实；附加价格收益分组回测已实现并以真实选定行情验证限定流程。全市场、完整旧版恢复及生产调度仍未验证，见[进展](progress.md)。
