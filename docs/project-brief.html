财务数据与特征工程框架

将公开财务数据整理为带来源、质量诊断及计算血缘的12项盈利、成长与偿债特征。东方财富负责主数据，新浪只作辅助核验。

采集与分页 → 证据 / 版本 / 观察 → 清洗 → 特征 → 双源及正式财报核对 → 质量、重放与价格收益

多公司、多报告期8公司×8季度×3表；192版本，768特征 / 232有值
公式及可重复性独立茅台样例目标12/12有值；主样本768/768冻结输入重放一致
双源及正式披露96位置：81匹配2024年报、3对应后续调整值、12缺值/定义不齐
收益回测8股票+ETF、165交易日，五组、双边成本、基准、净值与回撤

值得讨论的取舍

显式计量、累计转单季、非正基数与未知可比性拒算；内容版本与重复观察分开；修订立即失效并重算。三一案例展示“双源相同”仍可能与最初年报不同，不补造首次修订时间。
