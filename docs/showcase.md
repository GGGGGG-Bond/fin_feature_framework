## 价格收益入口与规则

```bash
.venv/bin/python -m fin_feature return-backtest \
  --signals data/demo/RUN/showcase/signals.json \
  --prices examples/snapshots/prices.json \
  --formation-date 2025-05-05 --end-date 2025-12-31 \
  --groups 5 --cost-bps 10 --benchmark 510300.SH \
  --output-dir data/new-price-backtest
```

信号使用`return-signals-v1`、单一feature_name，公司恰一条：secucode、report_date、feature_value、available_at、evidence_ref。未知/晚于形成日公开、未来报告期、非有限值或缺依据输入不入组，计划分母和排除原因保留。时间戳需时区，形成日为中国当地日终。

默认信号从2024正式年报资产/负债重建独立八份表，走普通版本、清洗、特征、血缘和重放链得到资产负债率。年报均在2025年3—4月发布，保守声明公开日期上界2025-04-30；这不是系统当时已知或历史字节归档。最新2026供应商资产负债表公告日在2025形成日全部拒绝，不能拿最新修订回填过去。

形成2025-05-05，信号升序、代码破同值，分组2/2/2/1/1；下一基准交易日5月6日前复权开盘入场、12月31日前复权收盘退出。等初始资金、碎股、固定持仓不调仓。单边10bps，倍率=`退出价/入场价×(1−费率)/(1+费率)`，基准同成本。净值从初始1计回撤；年化收益按实际持有日历天数，波动按日收益标准差×√252。

缺任何成员入场/中间/退出日价格，整组收益缺失、退出1，不删除成员或重排；样本不足组数也退出1；非法输入或已有输出目录退出2；完整成功退出0。导出summary.json/md、groups.csv、members.csv、nav.csv。G5−G1只是组合收益差，不是可交易多空收益。

手选八家跨行业公司仅验证流程，不证明因子有效。没有整手、容量、涨跌停和税项专门模拟；供应商前复权不等于独立实现的总收益指数。
