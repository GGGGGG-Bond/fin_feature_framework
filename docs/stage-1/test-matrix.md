# 阶段 1 验收测试矩阵

版本：stage1-v1。全部为必测验收场景；参数化测试可以合并实现，不要求一行一个测试。使用临时 SQLite、明确标为构造的财务 fixture 和 mocked HTTP，不请求全市场数据。

| 编号 | 场景/输入 | 必须观察到的结果 |
|---|---|---|
| T01 | 2024-12-31 报告公告于 2025-04-29，随后修订 | 增量回扫仍取得该期；公告水位不变成报告期过滤 |
| T02 | 同一成功范围重复采集 | raw 当前唯一键不重复、当前结果一致 |
| T03 | 某报表的第二页 HTTP 失败或业务 success=false | 该来源/公司单元不提交部分数据、不推进水位；CLI 非零 |
| T04 | 一公司失败、另一公司成功 | 成功单元可保留，摘要明确失败，整体非零 |
| T05 | 来源返回合法成功空数据/结构非法 | 分别标为空成功/失败，不能混为一类 |
| T06 | N=4，最近一期有多公告记录；排序未保证/实际不单调 | 有降序保证时完整取边界期；否则不提前截页或按单元报错；不按四行截断 |
| T07 | 公司最近一期不同；来源少于 N 期 | 分公司、分报表计算范围，不补造、不用全局最近期 |
| T08 | N=None、0、负数、布尔值、字符串 | None 不限；其他非法 N 请求前拒绝 |

| T18 | W_y=0.10、W_t=0.12，prev 另有值 | roe_change=2.0、roe_change_rate=0.2，必须使用去年同期 |

| T22 | 去年 Q3=300、全年=450，今年 Q1=180 | Q4=150，Q1 环比=0.2；缺 Q3 则 None |
| T23 | 连续上一季度缺失 | 不跳到更早期作为环比比较 |
| T24 | 跨期币种、单位、范围或版本未知/冲突；同原记录共享计量已证实/未证实 | 跨期拒算；同期比值仅在共享计量/范围可证时允许；字段各自保留引用，不乱取raw补证据 |
| T25 | A=100、L=120、E=-20 | 债务率=1.2、权益率=-0.2；不把余额做季度差分 |

| T31 | 同日版本、多次公告、未知公告日 | 当前选取可确定且标歧义；未知日不覆盖已知最新 |
| T32 | 同一输入、配置和 stage1-v1 重跑 | 数值等价，诊断可解释；不按运行时间比较一致性 |

| T35 | CLI backtest 帮助与报告 | 展示为盈利增长分析，写明代理；不暗示交易收益 |
| T36 | 干净临时环境安装、CLI --help | 项目可安装，入口可运行；不依赖当前工作目录偶然可导入 |

## 交付证据

实现 agent 提供基准/结果 commit、受影响测试清单、完整 pytest 摘要、数值 fixture 的定义和断言、打包/安装命令及结果。源映射必须分别标出代码已有映射、构造 fixture 的约定、真实文档或样本已验证的信息。

原 44 项测试是基线，不代表上述 36 类场景已有覆盖。修改公式相关预期需要指出对应契约条目，同时保留针对旧错误的回归。架构 agent 独立复核 T01、T03、T10—12、T18、T21—28、T30 和安装结果，不以实现 agent 的汇报代替验收。

有限真实样本只做明确范围的读验证，记录每个特征可计算率和 unknown 原因。如果缺少单位或版本可比证据，应暴露缺口；禁止把假定写入真实映射以让测试或覆盖率看起来通过。此阶段不作为双源、完整历史或生产验收。
