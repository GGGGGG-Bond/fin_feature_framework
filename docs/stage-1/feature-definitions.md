# 12 个特征定义

定义版本：stage1-v1。所有公式使用标准化输入；比例和增长输出小数，百分点变化输出百分点。API 原百分值不能直接混入输出。

符号：R=累计营业总收入，P=累计归母净利润，A=期末总资产，L=期末总负债，E=期末总权益；W=加权平均 ROE 小数，G=毛利率小数，C=流动比率倍数；t 为当期，y 为去年同一报告期，p 为连续上一季度。

| feature_name | 定义 | 单位 | 必要条件 |
|---|---|---|---|
| net_profit_margin | P_t / R_t | 小数 | 同公司、同报告期、同口径输入；R_t>0；展示名注明“归母净利润/营业总收入” |
| gross_margin_feat | G_t | 小数 | 采用经过单位和定义核验的累计销售毛利率；金融企业不适用 |
| roe_change | (W_t-W_y)*100 | 百分点 | 去年同一报告期、相同加权平均 ROE 定义及可比口径 |
| roe_change_rate | (W_t-W_y)/W_y | 小数 | 同上；W_y>0 |
| revenue_yoy | (R_t-R_y)/R_y | 小数 | 累计同比，累计区间和口径一致；R_y>0 |
| profit_yoy | (P_t-P_y)/P_y | 小数 | 累计归母净利润同比；P_y>0 |
| revenue_qoq | (r_t-r_p)/r_p | 小数 | 连续单季营收；r_p>0；r 为按下述方法得到的单季值 |
| profit_qoq | (p_t-p_p)/p_p | 小数 | 连续单季归母净利润；p_p>0；小写 p 表示单季利润 |
| debt_asset_ratio_change | (L_t/A_t-L_p/A_p)*100 | 百分点 | 两个连续季度的余额口径可比；两期 A>0 |
| current_ratio_change | C_t-C_p | 倍数差 | 单位、定义与范围一致；金融企业流动分类不适用时为空 |
| equity_ratio | E_t/A_t | 小数 | 权益合计与资产口径匹配；A_t>0；E 可为负 |
| debt_asset_ratio | L_t/A_t | 小数 | A_t>0、L_t>=0；允许结果超过 1 |

## 跨期、单季和增长规则

相同比较期必须为严格日期：同比回看去年同月同日；环比和余额变化只取相邻季度。缺季不能跳到更早期，年报不能拿上一年三季报作为同比。ROE 改为去年同期，不能比较一季度累计与半年累计 ROE。

累计流量转单季：Q1=当年 Q1 累计；Q2=半年累计-Q1；Q3=前三季度累计-半年；Q4=全年累计-前三季度累计。同币种、计量、合并范围及可比版本口径才可差分。资产、负债、权益等期末余额不差分。

计算当年 Q1 环比，需要上一年全年和 Q3 才能得到上一年 Q4。直接提供可信单季值时可使用，但不能从 API 环比增速倒推单季金额。缺任一必要输入或可比证据时输出 None 与原因。

四个增长特征一律按上述金额自算。来源增速只用于对照，阶段 1 不提供语义未经验证的 API 优先或兜底分支。比较基数为零或负数，增长率及 roe_change_rate 输出 None，原因 non_positive_comparison_base；不能自行采用绝对分母。当期利润为负、基准为正可计算负增长，例如 10 到 -5 为 -1.5。零值单季利润可真实存在，不能当缺失。

## 结果与兼容性

保持 12 个名称和长表输出；计算成功才写有限数值。缺失、未知单位、不可比、不适用、非正分母分别输出诊断，不能用 0 替代 None。允许 negative_percentage 等有解释的负结果，不允许 NaN/Inf。

相较初始实现，毛利率和资产负债率由百分值改为小数；ROE 比较改为去年同期；增长基数与自算策略改变。每条新 features 行及运行摘要、诊断必须显示 stage1-v1，并列出兼容变化。旧行视为 legacy-unversioned，查询与分析按定义过滤；同主键 legacy 覆盖默认拒写，建议使用隔离新库。不对已有库静默宣称新定义已生效或将旧单位行混入分析；默认测试和演示使用新建临时库，旧库重算需明确范围并保留原库。完整版本存储在阶段 2 完成。
