# 项目成果与完成范围

[返回文档总索引](../README.md#文档索引)

当前版本 **0.4.2**。项目提供从公开财务采集、证据留存、清洗到特征、双源核验和价格收益研究的完整流程。下载和复现见[成果与运行指南](interviewer-handoff.md)。

| 要求 | 实现与可查看结果 |
|---|---|
| 采集、存储、清洗、日志、导出 | 限频采集、分页与重试留证；版本、观察、当前投影和水位由单元事务共同提交；默认演示离线 |
| 12项财务特征 | 盈利、成长、偿债共12项；茅台、美的、宁德时代在2024年末目标期36/36有值；78项正式事实绑定PDF页、行列、原计量和内容摘要 |
| 多公司、多期 | 供应商视图8公司×8季度×3表、192版本、768结果/232有值；正式财报视图144结果/57有值，两类输入独立统计 |
| 双源核验 | 96位置：84双方有值且数值一致；81匹配2024年报、3对应后续比较列、12缺值/定义不齐 |
| 时间与修订 | 正式事实绑定其实际报表版本和可用日期上界；三一原年报与后续比较列并存；精确首次披露/修订时刻保持未知 |
| 质量与冻结重放 | 供应商768/768、正式财报144/144一致，包含空值和原因；提供原体对账、输入血缘和修订失效/重算 |
| 价格收益研究 | 五组单次回测；三个连续区间×三个成本假设×三个显式样本子集，共9场景，输出成员、排除原因和净值 |
| 工程验收 | GitHub Actions运行Linux Python3.12/3.14矩阵；完整验收包含文档、版本引用、回归和全部离线流程 |
| 查看与复算 | 完整ZIP解压打开START_HERE.html免安装查看；Linux/WSL使用bash run.sh，原生Windows使用Python UTF-8入口 |

数据和公式依据见[核验覆盖](verified-coverage.md)，供应商数值见[展示结果](../showcase/expanded.md)，实际环境与测试见[验收证据](acceptance.md)。

适用范围为固定八家公司和选定期间的工程流程验证。生产调度、全市场覆盖、策略样本外有效性及完整历史字节恢复不作为已验证能力；具体限制见[适用边界](gaps-and-weaknesses.md)。
