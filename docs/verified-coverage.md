当前版本 **0.4.2**；财务定义为stage1-v1。茅台、美的、宁德时代正式报表核验视图使用固定事实及显式口径声明，单位、比较基数和可比性检查贯穿计算链。

## 覆盖分母

| 输入类别 | 公司/期间 | 全位置及有值 | 目标期 |
|---|---|---|---|
| 原供应商字段 | 8公司×8季度 | 768位置、232有值、768/768重放一致 | 未知跨期口径仍为空 |
| 正式财报核验事实 | 3公司×4个选定期间 | 144位置、57有值、144/144重放一致 | 2024-12-31共36/36有值 |

两类输入独立，不能把36个核验目标数加到768的分母或称为供应商未知口径已经解决。其他报告期缺少比较期时仍为空。三公司每家26项无重复事实，共78项；出处和文件身份见[输入清单](../examples/reviewed/README.md)。

## 数据与口径

每家公司选用2024年度报告、2024第三季度报告和2024半年度报告。2023年末的同比输入来自2024年报比较列；期末总权益使用含少数股东的总权益，不用归母权益替换。毛利率分母使用营业收入；增长和归母净利率分母使用营业总收入。美的年报扣减成本括号先取费用金额；不把总成本当营业成本。

美的报表千元、宁德时代年报千元/季报万元、茅台元，逐项保存打印值和计量，再统一为人民币元；流动比率由披露的流动资产/流动负债相除得到倍数。Q4=全年-Q3累计，Q3=前三季度-半年累计；单季环比不是累计环比。对每份绑定输入保存声明及raw/metric/semantic摘要，移除声明后恢复unknown_unit/incomparable_basis拒算，旧冻结输入仍可重放。

Q4是全年累计减已披露前三季度累计的推导口径，可能包含年末审计调整和不同打印计量的精度差；不将其描述为独立审计的第四季度报表。业务季节性也不由环比增长率自动消除。

年度分季数据及“与已披露季度无重大差异”说明、同一公司合并报表定义共同作为本次选定流量的人工核验依据，声明只适用于固定数据。它不自动核准供应商当前记录或未来新采样。2023重列/比较列按当前年报列示口径使用，不追认成原始2023披露。

## 披露时间和修订

输出reviewed/disclosure-catalog.json绑定文档URL、PDF字节摘要及保守available_by；物理页在对应事实清单中。本次目标结果的输入期间集合采用所有所需报表上界的最大值，年报2023比较列也必须等到该年报可用。首次公开精确时刻、首次修订精确时刻及历史字节归档均不从报告期、URL或系统采集时间推断。

另输出disclosure-editions.json：三一2024原年报与2025年报的2024比较列同时保留，资产、负债、归母净利的差异均有出处。后续比较列的保守可用上界在2026，不能用于2025形成日；原年报不被改写。已有系统观察UTC、不可变版本/观察、截止日及冻结计算链继续记录从现在实际看到的内容。

## 滚动形成、样本子集和费用

```bash
.venv/bin/python -m fin_feature return-study \
  --signals data/demo/RUN/showcase/signals.json \
  --prices examples/snapshots/prices.json \
  --plan examples/return-study-plan.json \
  --output-dir data/new-return-study
```

[固定计划](../examples/return-study-plan.json)包含2025-05-05至06-30、06-30至09-30、09-30至12-31三个相邻区间；每期按当日之前可用的最新报告期信号重新分组。默认固定2024年报信号复用，不假称每季获得新信号。等日同报告期存在冲突版本时拒绝歧义；未知或未来公开的信号不进入形成日。

全8家公司分五组、非金融5家分两组、制造示例3家分两组；单边0/10/30bps得到9场景。子集为显式演示划分，不是申万等标准行业分类，也不是扩大的无偏行业样本。

每期末收盘平仓、下一期次交易日开盘买入，两侧各计费用、基准同样计费用；两次交易之间空仓收益为0，不赚取跨期跳空。净值按逐期财富乘积衔接，去重同日边界。任一计划成员缺少当日可用信号，或任一入场/中间/退出价格缺失，整场景不发布部分链式收益，不静默缩小分母。每期成员、排除原因、净值及成本敏感性CSV全部输出。

## 验收与边界

回归覆盖三公司独立期望数值、原始计量、事实变更拒算、声明移除与保存重放、比较列日期继承、未来版本筛选、逐期双边费用、跳空不获利、缺价/缺信号与冲突版本。真实GitHub双版本CI及交付复现记录见[验收](acceptance.md)。

金融企业毛利和流动分类仍不适用原工业定义；不为提高覆盖率映射异义科目。小样本、复权价格、碎股和理想交易仍有边界，不宣称策略有效或真实可执行。更大样本、标准行业因子、容量/整手/停牌/涨跌停/税项模型属于另行研究范围。
