# 验收记录

基础实现已经在Linux Python3.12.3及本机Linux Python3.14.6分别完成770项离线测试，11项联网测试未执行。三种离线演示分别重放24/24、48/48、72/72一致。受限真实验证另有一家两季度、三张表、三次请求、24/24重放，不冒称联网测试套件通过。

公开候选保留业务源码、原测试与32项公开事实引用；排除内部历史、机器配置、原始考核全文和私有运行资料。本候选的单独验证记录将写入[public-readiness.json](public-readiness.json)，不能将既有记录当作Codespaces云端已经验证。

公开样例信封为重建输入，不是供应商原始响应。96个真实核验位置中34人工核查一致、50有数值未查、12缺失。未知公开时间继续拒选，投资收益回测未实现。
