# 财务数据与特征工程框架 · 面试交付说明

**版本 v0.3.1 · 项目负责人 gezhijie · Python / SQLite / CLI**

项目将公开财务数据整理为带来源、质量诊断和计算血缘的12项财务特征，覆盖盈利、成长、偿债。主来源东方财富，新浪作辅助核验；第二来源不拼接主数据。

**主流程**：限频采集与分页 → 原始证据/版本/观察 → 清洗与标准化 → 特征 → 双源/正式财报核对 → 质量报告、重放及价格收益分组。

| 可查看结果 | 当前限定验收 |
|---|---|
| 多公司、多报告期 | 8家公司×8季度×3表，192报表版本；768特征、232有值 |
| 公式与口径 | 12项已实现；独立茅台正式财报样例目标期12/12有值 |
| 证据与可重复性 | 主样本768/768冻结输入重放一致；失败单元事务回滚 |
| 双源与正式披露 | 96位置：81匹配2024年报、3对应后续调整值、12缺值/定义不齐 |
| 收益回测 | 8股票+ETF基准、165交易日，五组、双边成本、净值与回撤 |

**值得讨论的取舍**：不靠数值大小猜单位；累计金额先转单季；负基数/未知可比性拒算；内容版本与重复观察分开；修订立即失效并重算。三一案例中两网站一致，但与最初年报不同，后续年报比较列解释了数值出处，未伪造首次修订时间。

**五分钟浏览**：打开结果页 → 按公司筛选 → 看三一双源差异 → 看空值原因与茅台12项完整样例 → 看价格收益与前视拒选 → 按需查看CSV和血缘。

**运行**：免安装打开结果包的`START_HERE.html`。Linux/WSL Python≥3.12运行`bash run.sh`；Windows有WSL时双击`run-demo.cmd`。首次安装需包源网络，默认演示不请求金融接口。

**范围与贡献说明**：项目需求、财务约束、版本演进和验收取舍是讲解重点；开发使用AI辅助编码与检查，结果属于项目本地自验证，不冒充独立第三方认证。固定字段来自真实采样，但离线API信封为重建；年报事实人工口径声明只绑定具体输入。八家手选公司不是全市场，收益只验证流程，未证明策略有效；未知历史修订、生产调度和云环境保留边界。
