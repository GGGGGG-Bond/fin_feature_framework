# 主要设计决策

[返回文档总索引](../README.md#文档索引)

| 选择 | 理由与代价 |
|---|---|
| Python、SQLite、CLI | 轻量可复现，保留清晰模块接口；不引入分布式平台 |
| 原始文件+数据库引用 | 保留逐字节证据；需要不可变发布和孤儿对账 |
| 内容版本与观察分开 | 同内容多次观察不重复制造版本，保留每次证据与时间 |
| 第二来源只核验 | 避免未经证明的口径混算；覆盖率不足时保留缺失 |
| unknown拒算 | 不伪造单位、可比性或历史日期，代价是部分特征为空 |
| 修订即时失效、按公司重算 | 先保证依赖链正确；精细调度以后按实际性能优化 |
| 内容绑定的人工口径声明 | 固定已核对输入可计算；保存完整配置与哈希，不能给任意新数据全局放行 |
| 面试主线优先 | 暂停新增基础设施；单命令、明确样例和HTML结果先收尾 |
| 当前代码重放 | 保证输入追溯和业务值对照；不承诺历史环境恢复 |

当前状态见[进展](progress.md)，实际结果见[验收](acceptance.md)。

## DEC-007：结果展示收敛与价格收益（0.3.0）

用户优先流程跑通和更丰富展示。本批不加schema或调度；沿用八公司样本扩到八季度，固定真实字段和母原体哈希，离线重建信封身份单独说明。双源数值一致、正式财报数字核对、严格可比性分层展示；三一调整差异保留，不放宽容差。新增独立return-backtest，不更改旧盈利代理语义。历史信号经正常版本特征链从已核对年报产生，公开时间保守声明，不借2026修订充作2025已知。小样本仅验计算，缺价保留分母且整组缺失。更多规则见[showcase.md](showcase.md)。

## DEC-008：以核验数据覆盖与轻量研究收尾（0.4.0）

原供应商未知跨期口径不放宽，新增三公司正式事实视图，分别统计144/57及目标36/36。比较列时间继承实际载有其内容的报表；保守available_by不冒充精确首次披露。研究使用现有价格链补滚动区间与成本敏感性，不增加行情全市场抓取、schema或生产执行层。CI优先实际跑通Python最低版本与当前版本，文档和发布引用由同一验收入口检查。
