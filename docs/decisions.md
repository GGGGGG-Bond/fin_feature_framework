# 主要设计决策

| 选择 | 理由与代价 |
|---|---|
| Python、SQLite、CLI | 轻量可复现，保留清晰模块接口；不引入分布式平台 |
| 原始文件+数据库引用 | 保留逐字节证据；需要不可变发布和孤儿对账 |
| 内容版本与观察分开 | 同内容多次观察不重复制造版本，保留每次证据与时间 |
| 第二来源只核验 | 避免未经证明的口径混算；覆盖率不足时保留缺失 |
| unknown拒算 | 不伪造单位、可比性或历史日期，代价是部分特征为空 |
| 修订即时失效、按公司重算 | 先保证依赖链正确；精细调度以后按实际性能优化 |
| 内容绑定的人工口径声明 | 固定已核对输入可计算；保存完整配置与哈希，不能给任意新数据全局放行 |
| 面试主线优先 | 暂停新增基础设施；单命令、明确样例和HTML结果先收尾 |
| 当前代码重放 | 保证输入追溯和业务值对照；不承诺历史环境恢复 |

当前状态见[进展](progress.md)，实际结果见[验收](acceptance.md)。
